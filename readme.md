DOM Learn what matters


DOM (Document Object Model) in JavaScript is a programming interface that allows you to interact with the structure of an HTML or XML document. The DOM represents the document as a tree of nodes, where each node corresponds to a part of the document, such as elements, attributes, and text.

Key Points:
Structure of a Web Page: The DOM creates a structured representation of the page, where HTML elements (like <div>, <p>, <h1>) become objects that can be manipulated with JavaScript.

Tree-like Structure: The document is represented as a tree structure, with the document itself as the root, and HTML elements as branches and leaves.

Dynamic Interaction: You can dynamically change the content, structure, and styles of a web page by using JavaScript to manipulate the DOM

Project 1 = Add friend feature with same button

description = This project aims to implement an "Add Friend" feature in a social platform, where users can send and manage friend requests using a single button. The button will dynamically toggle between "Add Friend" and "Pending Request" based on the status of the user's interaction with another user. When the button is clicked, the system will send a friend request if no request has been made, or display a "Pending Request" label if the request is still awaiting approval. Once the request is accepted, the button will change to "Friends" to reflect the successful connection.

Key Features:

Dynamic button that updates based on friend request status.
Real-time update of friend status between users.
Seamless user experience with a single interaction point for managing friend requests.


Project 2 = Instagram like button
Description:

This project focuses on creating a "Like" button similar to the one found on Instagram, allowing users to interact with posts by expressing their approval. The button will toggle between "Liked" and "Unliked" states, updating both visually (e.g., changing the icon from a heart outline to a filled heart) and functionally (updating the like count). Users will be able to like and unlike posts with a single click, and the like count will be updated in real-time for the post. This feature enhances user engagement and interaction on the platform, creating a seamless and intuitive way to show appreciation for content.

Key Features:

Toggleable "Like" button that updates visually and counts in real-time.
Smooth and responsive interaction with instant feedback.
Ability to like and unlike posts, with a corresponding update in the like count.

Project 3 = Custom cursor
Description:

This project aims to create a custom cursor that enhances the user interface of a website or application. Instead of using the default system cursor, the custom cursor will be styled to match the design and branding of the site, providing a unique and interactive experience. Key Features:

Customizable cursor style (e.g., color, shape, size) to match website design.
Dynamic cursor changes based on user interaction (hovering, clicking, etc.).
Smooth and responsive movement that complements the overall UI/UX.

Project 4 = Multiple image hovering animation

Description:

This project focuses on creating an engaging and interactive animation effect for multiple images on a webpage. When a user hovers over any image, a smooth animation will be triggered, such as zooming in, fading, or rotating. Each image will have a unique hover effect, ensuring that the interaction feels dynamic and visually appealing. Multiple images with individual hover animations (e.g., zoom, rotate, or fade effects).

Project 5 = Instagram story feature

Description:

This project focuses on implementing an Instagram-like story feature where users can share short, temporary content in the form of photos, videos, or text that disappear after 24 hours. Users can post stories that are displayed in a slideshow format, with the ability to add filters, text, stickers, and emojis for personalization. The feature will allow users to view stories from their friends or followers by swiping through them, and will also provide interaction options like reacting with emojis or replying to a story.

Key Features:

Post and view temporary content that disappears after 24 hours.
Add filters, text, and interactive elements to personalize the stories.
Slideshow format for seamless viewing, with swipe functionality.
Option to react or reply to stories for better user engagement.
